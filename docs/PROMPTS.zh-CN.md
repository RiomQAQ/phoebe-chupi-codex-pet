# 提示词示例

[English](PROMPTS.md) · **简体中文** · [文档目录](README.zh-CN.md)

使用模板前先附上对应参考图。方括号内容替换成具体状态、帧位置或问题，每次只生成、编辑一帧。

## 建立角色基准

先根据社区参考确定坐姿和抱电脑姿势，再制作动画帧。

```text
根据附上的正面、侧面、背面参考，绘制一只透明背景的菲比啾比。
保留紧凑的 Q 版比例、浅金长发、宽白帽与深紫帽带、分层紫色眼睛、
白色服装、深色手套、条纹腿部和深色鞋。

蓝色发夹保持在观看者右侧，呆毛和蓝布在左侧。
使用深色外轮廓和金棕色内部发丝线。

姿势：[坐着使用一台打开的蓝灰色电脑／抱着同一台合上的电脑]。
电脑只有一层屏盖、一处铰链和一套键盘，双手位置清楚合理。
完整保留帽子、头发、双手和双脚，并留出边距。
一只角色，透明背景，不要文字和标签。
```

确认基准前，对比脸型、头身比、帽宽、配饰方向和电脑结构。

## 编辑单张动作帧

附上姿势基准和一张已认可的相邻帧。

```text
把附图角色修改成一张动作帧。
状态：[waiting]。位置：[第 2／6 帧]。变化：[轻微歪头，期待回复]。

保留角色身份、头身比例、帽子大小、长发轮廓、紫色眼睛结构、线宽、
服装、配饰方向和电脑结构。
相机、坐姿身体、双脚和电脑位置保持稳定。
相邻帧只用于判断动作幅度，不用来重新定义角色造型。
只修改预定的头部、表情或手部动作，背景透明，输出一张独立帧。
```

移动帧写明屏幕方向、支撑腿和步态阶段，左右分别画。坐姿小跳写明起跳、最高点、下降或落地，继续使用打开的电脑和统一缩放基准。

## 修复局部问题

说明问题的位置和表现，并附上对应部位的基准图。

```text
修复[电脑右侧重复的手套]。
依据角色基准，恢复为[一只与白色袖子连接的手]。
保留已有表情、轮廓、比例、配饰和所有不受影响的特征。
继续保持一台电脑和透明背景。
```

修复后重新检查完整轮廓及相邻帧。

## 绘制 Dot 转头姿态

方向使用屏幕坐标。[格式说明](FORMAT.zh-CN.md#转头方向)列出了全部 16 个角度。

```text
绘制 [090] 方向：角色应当明确看向[屏幕右侧]。
角度从屏幕正上方顺时针增加：000 上、090 右、180 下、270 左。

用头部朝向、眼神、脸部形状和帽顶可见面积表达方向。
保持已有紫色眼睛的画法和配饰方向。
身体、电脑、双脚、相机、缩放和地面接触点保持稳定。
只输出一张透明背景帧，坐姿身体不随头部一起转向。
```

先完成四个正方向，再补中间姿态。每新增一张，都对比前后两个方向。

## 审查单帧与完整动作

提供角色基准、相邻帧、原生尺寸静帧及实际循环。

```text
对照基准图审查提供的帧和动画。
检查角色一致性、头身比、配饰方向、双手、面部线条、电脑结构、
轮廓颜色、透明度和位置对齐。

查看九类动作、十六方向循环，以及待机—小跳—待机的衔接。
检查首尾接续、表情变化、角色大小、道具连续性和落地位置。

每项结论给出“通过／需留意／不通过”，注明对应帧或过渡、
可见依据和具体修改方向。区分有意的眨眼姿态与画面错误。
不要推断所提供媒体中没有展示的动作。
```

根据结果定位修复，再重做受影响的对比。文件校验另行完成。

## 无标签方向审查

不提供文件名、方向标签和答案。先收集独立判断，再揭晓预期方向。

```text
逐组判断无标签 A/B 图片的视线方向。
用屏幕坐标分别描述两张图：左／右，或上／下。
给出把握程度和可见依据。不确定时直接说明。
只依据所提供的图片，不查看答案表。
```

保留分歧，对照顺序转头循环核查。汇总和通过标准见[方向审查](REVIEW.zh-CN.md#方向审查)。
