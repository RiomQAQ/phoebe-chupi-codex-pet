# 审查与校验

[English](REVIEW.md) · **简体中文** · [文档目录](README.zh-CN.md)

画面、动作和发布文件分别检查。造型以基准姿势为准，发布验收以最终 WebP 为准。

## 逐帧检查

每个有效格都在浅色和深色背景下看一遍。先按原生 **192 × 208** 尺寸检查，定位问题时再放大局部。

| 检查项 | 通过标准 |
| --- | --- |
| 角色一致性 | 脸、帽子、头发、服装和头身比例符合基准。 |
| 配饰 | 发夹在观看者右侧，呆毛和蓝布在左侧。 |
| 肢体 | 只有预期的两只手和手臂，手套与袖口连接清楚。 |
| 面部 | 紫色眼睛、眉毛、下巴和嘴保持一致，没有重复杂线。 |
| 电脑 | 一层屏盖、一处铰链、一套键盘，双手接触位置合理。 |
| 轮廓 | 深色外线连续，金棕色内部发丝线保留原色。 |
| 透明度 | 没有不透明底色、轮廓裁切、杂色边或内部透明洞。 |
| 位置 | 应当静止的身体、电脑和地面接触点保持稳定。 |

改动帧要对比基准图、前后帧，以及相同姿势的其他状态。归一化和编码后重新检查。

## 检查完整动作

- 按预期速度播放九类动作，检查每个循环的首尾衔接。
- 查看 `idle → jumping → idle` 的起跳、电脑跟随和落地归位。
- 把工作、等待、检查和求助的表情连起来看，确认是同一个角色。
- 对比两个移动方向的比例和配饰位置。
- 播放 16 个转头方向及首尾循环，分别观察身体、电脑的漂移与头部动作。

可使用[全部动作](../previews/all-states.gif)、[小跳衔接](../previews/idle-jump-idle.gif)、[转头循环](../previews/look-loop.gif)和[深色预览](../previews/dark)。GIF 的颜色较少；[PNG](../art/final/spritesheet.png) 与[原像素裁剪帧](../art/frames)保留发布图片的完整像素。

## 方向审查

先看带标签的方向总览和顺序循环，再用无标签 A/B 图片判断实际朝向：

1. 比较 7 组水平、7 组垂直方向，四个正方向必须清楚。
2. 隐藏标签和答案，打乱 A/B 顺序。
3. 由 3 名独立审查者说明画面看向的屏幕方向及依据，允许回答不确定。
4. 揭晓答案前保存判断，再按每张图的严格多数汇总。
5. 有分歧时回到连续动作中核对，再决定保留或修复。

v1.0.1 由 3 名 AI 审查者完成方向盲看，14 组多数判定均通过。独立答案、答案表和全帧复查见[检查记录](repair-qa/README.zh-CN.md)。

## 当前结果

以下结果对应 **v1.0.1** 发布文件，文件标识见 [validation.json](validation.json) 和 [production-review.json](production-review.json)。

| 检查 | 结果 |
| --- | --- |
| 布局 | 1536 × 2288；73 个有效格，15 个全透明格。 |
| 导出一致性 | PNG 与无损 WebP 解码后的 RGBA 像素相同。 |
| 裁剪帧 | 73 张裁剪图均与对应格子一致。 |
| 原图颜色 | 73 格均与清理前的认可原图一致。 |
| 描线恢复 | 恢复 88,948 个可见像素的 RGB；263,885 个深色描线像素比对无差异。 |
| 小跳 | 最高抬升 21 px，落地偏移 0 px。 |
| 转头位置 | 横向中心最大偏移 3.5 px，宽度比最大 1.0625。 |
| 画面检查 | 73 帧均检查浅深背景，另有一轮独立复查和原生尺寸播放检查。 |
| 源图档案 | 742 张不同源图，对应 1,290 个工作文件实例。 |

动作测量采用 alpha > 16 的可见边界。`validation.json` 的原始边界包含所有非零透明像素，两种测量方式不要混用。

## 已知限制

- `045` 与 `067.5` 看起来接近。
- `225 → 247.5` 比相邻姿态的变化更明显。这两项微调记录在 [Issue #2](https://github.com/RiomQAQ/phoebe-chupi-codex-pet/issues/2)。
- 眨眼包含半闭眼和闭眼，减少动态效果或应用时序可能使某个姿态停留。
- 已检查 macOS 桌面端和 Dot 的表现，Windows 画面尚未实测。

[描线修复记录](OUTLINE-REPAIR.zh-CN.md)说明了 v1.0.0 的清理错误。导出检查需要覆盖原图颜色；如果两种格式都已有同一个错误，仅比对两者无法发现。

## 运行文件校验

安装仓库依赖后，使用 Python 3.10+：

```sh
python3 scripts/validate.py --report docs/validation.json
python3 -m unittest discover -s tests
```

校验器检查五字段清单、静态 v2 图片、格子数量与边距、PNG/WebP 一致性、最终裁剪帧、原图颜色、档案哈希、解码、元数据、常见隐私标记、文件大小和发布校验值。回归测试会拒绝有问题的 v1.0.0 整图，并检查三处已确认的头发像素。

颜色检查以 v1.0.1 的认可原图为基准。有意修改图片时，需要经过审查的新基准和校验值，同时保留历史原图与回归用例。CI 运行文件校验和回归测试，画面审查仍需单独完成。
