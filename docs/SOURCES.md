## Format and README references

- [Official pet-install URI documentation](https://learn.chatgpt.com/docs/reference/commands): native import with an HTTPS image URL and explicit `spriteVersionNumber=2`.
- [Official Pets documentation](https://learn.chatgpt.com/docs/pets): current desktop selection/refresh behavior and the separate web-upload restrictions.
- [sherlidian01-web/phoebe-codex-pet](https://github.com/sherlidian01-web/phoebe-codex-pet): concise bilingual presentation, animation previews, and installation organization. This repository does not copy its sprite assets or assume a permissive asset license.
- [HanaAyane/remielle-codex-pet](https://github.com/HanaAyane/remielle-codex-pet): detailed installation sections, preview grouping, and an actual five-field v2 manifest example. Its prose and scripts were not copied.
- [legeling/awesome-codex-pet](https://github.com/legeling/awesome-codex-pet): gallery navigation, visible source attribution, and portable local pet packaging.

## What is archived here

All 742 distinct project working images are preserved: generated originals, canonical studies, individual frames, comparison boards, contact sheets, preview images, rejected drafts, character samples, the rolled-back awake experiment, and the user-selected turnaround/crops. Byte-identical working copies are deduplicated and mapped in [art/index.json](../art/index.json). Public previews and exact final-atlas crops are additional files.

Third-party bulk research downloads, unrelated product images, private application screenshots, local account data, chat logs, and upload receipts are excluded. They are not required to install, inspect, or reproduce the workflow. Expiring private media URLs have been replaced by stable public source links.
