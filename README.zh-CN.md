## 三步快速安装

无需安装任何第三方插件，安装包内只有两个轻量文件：`pet.json` 与 `spritesheet.webp`。

1. **下载解压**：获取最新发布的 **[phoebe-chupi-v1.0.2.zip](https://github.com/RiomQAQ/phoebe-chupi-codex-pet/releases/download/v1.0.2/phoebe-chupi-v1.0.2.zip)** 并解压。
2. **放入宠物目录**：把解压出的 `phoebe-chupi` 文件夹放到 Codex 的 `pets` 目录下：

   ```text
   ~/.codex/pets/                      # macOS 默认路径（Windows 为 %USERPROFILE%\.codex\pets\）
   └── phoebe-chupi/
       ├── pet.json                    # 5 字段标准 v2 清单
       └── spritesheet.webp            # 1536 × 2288 无损透明精灵整图
   ```

3. **在应用中启用**：打开 Codex 桌面端 **设置 → Pets（或 Mini 与虚拟宠物）**，点击刷新列表，选中 **Phoebe Chupi · Coding Companion** 即可。

- **命令行一键安装（克隆仓库后）**：
  - 本地复制安装：`python3 scripts/install.py --local`
  - 调用官方 URI 原生导入：`python3 scripts/install.py`
- 升级旧版本、保留原有宠物身份及常见显示问题排查，请见 [安装与更新指南](docs/INSTALL.zh-CN.md)。
